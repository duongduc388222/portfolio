// INTRO

I work on efficient large language model inference — making models run faster, longer, and cheaper without giving up accuracy. I'm a Computer Science and Mathematics student at Grinnell College, researching across labs at Rice and Stevens, where my work centers on KV-cache management and inference-time reasoning: the place sampling, optimization, and systems meet. Lately I've been carrying that efficiency work into agents running on edge hardware, where inference cost compounds and smarter memory and compute decisions matter most. I try to optimize the whole pipeline, not a single model call. If you're working on efficient ML, NLP, or inference-time reasoning, I'd like to hear from you.
